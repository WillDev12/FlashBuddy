# Import from Saved Quizlet HTML

This method works in **any** version of FlashBuddy — no scraper server or internet connection required after saving the file. You save the Quizlet page to your device and upload it directly.

## How to Use

1. Open the Quizlet set you want to import in your browser.
2. Make sure all the cards are visible (scroll to the bottom to trigger lazy loading if needed).
3. Press **Ctrl+S** (Windows/Linux) or **Cmd+S** (Mac) to save the page.
4. When prompted, choose **Webpage, Complete** or **Webpage, HTML Only** — either works.
5. Open FlashBuddy and click **Manage** → **+ New Deck**.
6. Under **Import from Quizlet → By Saved HTML File**, click **Upload Quizlet .html**.
7. Select the `.html` file you saved.
8. Cards will be imported automatically. Give the deck a name and click **Save Deck**.

## Notes

- This works on public and private sets (since you're already logged in when you save the page).
- If you get "No cards found", scroll all the way to the bottom of the Quizlet page before saving — some cards load lazily.
- Works offline once the file is saved.
